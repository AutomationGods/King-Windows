# King for Windows

King is the desktop command center for e-commerce creative: generate product shots, manage products, characters and prompts, and run your stores and ad accounts from one app.

This page is for **Windows**. The Mac version is separate and updates itself. On an Android phone? Get [King for Android](https://github.com/AutomationGods/King-Android).

## Install

1. Download `King-1.10.0-x64-Setup.exe` from the link above.
2. Double-click it.
3. If Windows shows **"Windows protected your PC"**, click **More info**, then **Run anyway**. This appears because the app isn't code-signed yet.
4. Pick where to install it (or keep the default) and click **Install**.
5. Open King from the desktop shortcut or the Start menu.

## Update

The installed version checks for new Windows releases on its own. You can also open **Settings** (the gear in the sidebar) and click **Check**. If you use the portable file, download the new one from the link above.

## Uninstall

Go to **Settings → Apps → Installed apps**, find **King**, and click **Uninstall**. Your library, settings and API keys stay in `%APPDATA%\king`. Delete that folder if you want them gone too.
